# مرشد MORSHID

**مرشد** رفيق سياحي ذكي لزوار **الرياض والمملكة العربية السعودية ومعرض إكسبو 2030 الرياض**. يساعد الزائر على معرفة ما يستحق الزيارة، ولماذا هو مهم، وكيف ينظّم زيارته في خطة عملية. يعمل التطبيق باللغتين العربية والإنجليزية.

يقدّم التطبيق شخصيتين ذكيتين:
- **عارف**: يهتم بالتقنية والابتكار والاستدامة.
- **رؤية**: تهتم بالثقافة والتراث والفنون والسياحة.

## الفكرة ورحلات المستخدم

1. **اسأل ثم خطّط:** يتحدث الزائر مع عارف أو رؤية، فيحصل على اقتراحات أو مسودة خطة يعدّلها ثم يحفظها في «خططي».
2. **اكتشف ثم خطّط:** يتصفح الأماكن ويبحث ويفلتر على الخريطة، ثم يفتح تفاصيل المكان ليضيفه إلى خطة أو يسأل عنه.
3. **إكسبو 2030:** يتصفح مناطق المعرض وأجنحته على مخطط تفاعلي، ثم يضيف الأجنحة إلى خطة إكسبو.
4. **متابعة الخطة:** يبدأ الخطة، ويتنقل بين محطاتها مع رابط Google Maps، ويعلّم كل محطة عند إنجازها.
5. **الحساب:** تسجيل الدخول، وإعدادات اللغة والمظهر والإشعارات، والرصيد والاشتراك.

## هيكل المستودع

| المجلد | التقنية | المنفذ |
|---|---|---|
| `frontend/` | Next.js 16، React 19، next-intl (عربي/إنجليزي)، TanStack Query، MapLibre | 3000 |
| `frontend/mobile/` | تطبيق Expo يعرض نسخة الويب داخل WebView (لأندرويد وiOS) | 8081 (Metro) |
| `backend/` | Spring Boot 4، Java 21، JPA، MySQL | 8080، والمسار الأساسي `/api/v1` |

## حالة الربط بين الفرونت اند والباك اند

يعمل الفرونت اند في **الوضع الهجين** (`NEXT_PUBLIC_DATA_SOURCE=hybrid`). الأقسام التي يقدّم لها الباك اند API متوافقاً تُقرأ منه، وبقية الأقسام تعمل على البيانات التجريبية.

### ✅ مربوط بالباك اند

| القسم في التطبيق | الـ Endpoint |
|---|---|
| اكتشف: البحث والفلاتر والخريطة | `GET /api/v1/places` |
| تفاصيل المكان | `GET /api/v1/places/{id}` |
| الأماكن المميزة | `GET /api/v1/places?featured=true`، ومع الرجوع إلى الاختيارات التجريبية إن لم يُعلَّم أي مكان كمميز |
| الأماكن المستخدمة داخل الخطط والمحادثة | `GET /api/v1/places?ids=...` |
| مخطط إكسبو: المناطق والمرافق والمسارات | `GET /api/v1/expo/layout` |
| أجنحة إكسبو مع البحث والفلترة | `GET /api/v1/expo/booths` |
| تفاصيل الجناح | `GET /api/v1/expo/booths/{id}` |

### ⏳ المتبقي (يعمل حالياً على البيانات التجريبية)

| القسم | سبب عدم ربطه |
|---|---|
| خططي (إنشاء وتعديل وبدء الخطة) | الـ API الحالي `/visit-plans` لا يطابق عقد الفرونت، ولا توجد مصادقة لحماية بيانات المستخدم |
| المحادثة مع عارف ورؤية | الـ API الحالي `/conversations` مبني على `userId` بلا مصادقة، ولا يدعم البث (SSE) الذي تحتاجه الواجهة |
| تسجيل الدخول والملف الشخصي | لا يوجد نظام مصادقة (JWT أو Session) في الباك اند |
| الإشعارات | لا يوجد API |
| الاشتراك والرصيد | لا يوجد API |
| المجموعات (Collections) | الـ endpoint موجود لكنه يُرجع قائمة فارغة حالياً |
| المقالات والمدونة | محتوى ثابت داخل الفرونت اند |

لربط قسم جديد، يجب أولاً بناء الـ API في الباك اند حسب العقد الموجود في `frontend/docs/api-contracts.md`، ثم إضافة القسم إلى `LIVE_DOMAINS` في الملف `frontend/src/shared/config/env.ts`.

## البيانات التجريبية

جميع البيانات الحالية **توضيحية**، وليست بيانات رسمية:

- **الأماكن (19 مكاناً):** أماكن حقيقية في الرياض وخارجها، مثل قصر المصمك والدرعية والمتحف الوطني والعلا. إحداثياتها مأخوذة من OpenStreetMap، والمصدر مسجّل في الحقل `locationSource`. أما الأوصاف وأوقات العمل والمدد المقترحة فهي تجريبية ويجب التحقق منها قبل الزيارة. الصور حالياً صور مؤقتة.
- **إكسبو 2030:** فيه 5 مناطق و22 جناحاً و8 مرافق، وكلها **متخيَّلة** وليست المخطط ولا البرنامج الرسمي لإكسبو 2030. الإحداثيات محلية على مخطط بمقاس 1000×700، وليست إحداثيات GPS. يُحمّل الباك اند هذه البيانات تلقائياً عند التشغيل من `backend/src/main/resources/demo/`.
- **الخطط والمحادثات والإشعارات والمستخدمون:** بيانات وهمية داخل الفرونت اند في `frontend/src/entities/*/api/demo/`، وتُحفظ في متصفح المستخدم.
- **ردود المساعد:** ردود تجريبية جاهزة. يدعم الباك اند الاتصال بـ OpenAI عند ضبط `OPENAI_API_KEY`، لكن المحادثة غير مربوطة بالواجهة بعد.

## التشغيل محلياً

### الباك اند
يحتاج MySQL على المنفذ 3306. قاعدة البيانات `morshid_expo2030` تُنشأ تلقائياً.

```bash
cd backend
./mvnw spring-boot:run
```

| المتغير | الافتراضي |
|---|---|
| `PORT` | `8080` |
| `DB_URL` | `jdbc:mysql://localhost:3306/morshid_expo2030?createDatabaseIfNotExist=true` |
| `DB_USERNAME` / `DB_PASSWORD` | `root` / فارغة |
| `MORSHID_CORS_ALLOWED_ORIGINS` | `http://localhost:*,http://127.0.0.1:*,https://*.vercel.app` |
| `OPENAI_API_KEY` | فارغ |

### الفرونت اند
```bash
cd frontend
cp .env.example .env.local
npm install
npm run dev
```
لتصمفج المنصه https://morshid-three.vercel.app/ar
| المتغير | القيمة |
|---|---|
| `NEXT_PUBLIC_DATA_SOURCE` | `mock` لكل شيء تجريبي، أو `hybrid` (الافتراضي)، أو `http` |
| `NEXT_PUBLIC_API_BASE_URL` | `http://localhost:8080/api/v1` |
| `NEXT_PUBLIC_LIVE_DOMAINS` | `places,expo` |

> على الجوال أو المحاكي لا يشير `localhost` إلى جهازك. استخدم عنوان IP المحلي لجهازك، أو `10.0.2.2` في محاكي أندرويد.



## معالجة الأخطاء
جميع الطلبات تمر عبر عميل HTTP موحد في `frontend/src/shared/api/http-client.ts`. هذا العميل يضبط مهلة 15 ثانية، ويتحقق من شكل الرد باستخدام Zod، ويحوّل الأخطاء إلى رموز موحدة. يرى المستخدم رسائل واضحة بالعربية والإنجليزية لهذه الحالات: انقطاع الاتصال، وتأخر الرد، وعدم وجود العنصر (404)، وخطأ الخادم (5xx).
