# MORSHID — Implementation Plan (v1)

> Status: **Proposed (part of Gate B)**. Implementation starts **only after Gates A and B are approved**.
> Each phase is small and testable. It ends with the checks listed, a short summary, and a request for feedback. Minor design details are decided within D-009. Only material deviations from reviewed references are raised as questions, one at a time.

**Per-phase quality bar (amended by D-029):** `npm run typecheck` and `npm run build` only. No new tests are written, and no test or viewport runs are done (user instruction). Results are reported exactly as they come out. The "Exit criteria" column below still describes the intended behavior, but its test items no longer apply.
